PKCS#11 is an interface for applications to use cryptographic tokens, including HSMs and secure elements. Applications load a provider module to find keys and request operations such as signing or encryption.

An integration review includes:

- The provider module being loaded.
- Session management and authentication.
- Key attributes that restrict use or export.
- Error handling when the token is unavailable or a session fails.

The guide introduces the API and complements the [HSM overview]({{ '/hardware-security-modules/' | relative_url }}).
